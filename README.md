# Yugatn eWorld

A social network designed as a navigable 2D world rather than a conventional profile-and-menu application.

## Marketplace (Avito-style)

Users can **list and sell their own goods**: categories, search, reserve, pay in **YC** or meet offline.  
See [`docs/MARKETPLACE_V0.1.md`](docs/MARKETPLACE_V0.1.md).

## Security

- Domain security + server `SECURITY_HEADERS`, `/healthz`
- OWASP: [`docs/OWASP_TOP10_EWORLD.md`](docs/OWASP_TOP10_EWORLD.md)

## Features

Avatar shop · travel · cinema · podcasts · wellness/health · school/ACL · voting · YC · **C2C marketplace** · voice (RU/EN).

## Run

```bash
npm install && npm start
npm test
```
