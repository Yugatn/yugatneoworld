# UX — Spatial Interaction

## Core loop

The user enters the apartment as an avatar, moves toward an object, enters its interaction radius, activates it and receives a contextual interface only when needed.

Example: avatar approaches mailbox, mailbox highlights, user interacts, messages open, user returns to the same world position.

## Object affordances

Objects should communicate their function visually. A mailbox should look like a mailbox; a television like a television; a laptop like a laptop. Avoid replacing the world with generic icon grids.

## Navigation

Support keyboard movement, pointer or touch movement where appropriate, collision boundaries, room transitions, camera following and interaction radius.

## Contextual UI

Contextual UI is subordinate to the world. It should appear near the active object or as an accessible overlay, explain the capability, support keyboard/focus access and return the user to the world without losing position.

## Personalization

Users should customize the apartment physically: move, replace and add furniture and objects; change wall/floor appearance; place media; change avatar clothing and visual identity.

## Social presence

Visitors should appear as avatars rather than only names in lists. Lists remain available as utility and accessibility views.

## Design goal

The user should understand what to do by looking at the room.

**The environment is the menu.**
